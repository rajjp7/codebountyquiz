Case Dossier

A creator posts five short videos — A, B, C, D and E — as part of a viral online challenge. Hours later, the creator reveals that exactly one video is an AI-generated deepfake. The other four are genuine recordings. Visual inspection is useless: the fake looks perfect. The only way to identify it is to check what each video claims against the other evidence.

Core Axiom 1: The deepfake contains exactly TWO false claims (0 true claims).
Core Axiom 2: Every genuine video contains exactly ONE false claim (1 true, 1 false).

Hint 1 — The Ten-Digit Lock +
There are exactly 10 different letters in the two equations: R, A, J, Z, E, O, C, G, N, S. All digits from 0 to 9 are used exactly once.
Hint 2 — Don't Start From the Left +
Look at the addition column by column, starting from the units column: A + O = E in both RAJA + ZERO and GANGA + ZERO. The units addition is identical in both equations!
Hint 3 — Watch the Carries +
In RAJA + ZERO = CRORE, two 4-digit numbers sum to a 5-digit number (CRORE). The carry into the ten-thousands column can only be 1, which directly fixes C = 1!
Hint 4 — The Leftmost Digit +
With C = 1, in the thousands column R + Z (+ carry) must produce 1R. Since R + Z ≥ 10, examine the heavily constrained carry conditions.

Rules of Hashiwokakero (Bridges)

Classic logic puzzle rules from puzzle-bridges.com.

1. Orthogonal Bridges Only

Bridges travel straight horizontally or vertically between islands in the same row or column. No diagonal bridges.

2. Exact Bridge Counts

The number on each island represents the exact count of connected bridges (1 to 8). Completed islands light up green.

3. Maximum Two Bridges

At most two parallel bridges may connect any pair of islands (single bridge = 1, double bridge = 2).

4. Bridges Cannot Cross

Bridges cannot cross or jump over any other bridge or island. They only connect adjacent line-of-sight neighbors.

5. Single Connected Network

All islands across the board must form one unified connected network. Disconnected sub-loops are invalid even if numbers match.
